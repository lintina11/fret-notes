# fret-notes

A Vue 3 web app for guitarists — visualize chords on an interactive fretboard, keyboard, chord chart, and tablature view.

## Features

- Fretboard diagram
- Piano keyboard view
- Chord chart
- Tablature display

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- [Vue 3](https://vuejs.org/) with `<script setup>` SFCs
- [Vite](https://vitejs.dev/)
- Sass
